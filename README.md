# Oracle APEX Custom JavaScript & UI Enhancements

## Overview
This repository provides reusable JavaScript utility snippets and PL/SQL integration code designed for Oracle APEX applications. It covers dynamic actions, client-side data validation, interactive grid manipulation, and REST API consumption.

## Components Included
- `apex_ui_utils.js`: Client-side JavaScript helpers for Oracle APEX dynamic actions and notifications.
- `rest_integration.sql`: PL/SQL procedures using `APEX_WEB_SERVICE` to handle external web APIs.
